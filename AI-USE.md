# AI Usage Disclosure

## Project: HelpDesk Lite API

This document discloses the use of AI assistance during the development and documentation of the HelpDesk Lite backend application.

## 1. AI Tool Used

| Tool | Purpose |
|---|---|
| ChatGPT (OpenAI) | Technical guidance, debugging assistance, implementation suggestions, and documentation support |

## 2. Areas of AI Assistance

ChatGPT was used as a supporting development resource in the following areas:

- **Project planning:** Discussing backend architecture, package organization, and separation of responsibilities.
- **Implementation guidance:** Reviewing approaches and providing examples related to Spring Boot, JPA entities, DTOs, repositories, services, controllers, and database migrations.
- **Business logic:** Understanding ticket status transitions, validation rules, and status history management.
- **Debugging:** Investigating compilation errors, dependency and import issues, testing configuration, and database setup.
- **Testing preparation:** Preparing Postman request examples, test scenarios, and expected API responses.
- **Documentation:** Assisting with the README and project documentation.

AI-generated suggestions were reviewed and adapted as part of the development process.

## 3. Developer Contribution

The developer was responsible for making implementation decisions, integrating application components, configuring the development environment, reviewing suggested solutions, and evaluating the resulting application behavior.

AI assistance was used to support learning and problem-solving rather than replace the developer's responsibility for the implementation.

## 4. Verification and Responsibility

The developer is responsible for understanding, reviewing, testing, and explaining the submitted implementation.

Verification activities include Maven compilation, automated tests, database and migration checks, and API testing through Postman. Only successfully completed checks are considered verified.

## 5. Declaration

AI tools were used transparently as supporting resources during development. The developer remains responsible for the submitted source code and its correctness.
